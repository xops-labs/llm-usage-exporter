## How To Add Yourself

1. Fork the repository.
2. Add a row to the table above.
3. Open a pull request with a short note about how you use `llm-usage-exporter`.

You can list a company, startup, open-source project, internal platform team, or individual builder. If your usage is
private, vague descriptions are fine.
